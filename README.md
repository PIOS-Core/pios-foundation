# PIOS

**Professional Intelligence Operating System**

## Цель проекта

PIOS — это платформа для накопления, анализа и повторного использования управленческих решений.

Первая версия (MVP) позволяет:

- фиксировать управленческие решения;
- сохранять контекст;
- добавлять фактический результат;
- использовать накопленный опыт для будущих решений.
